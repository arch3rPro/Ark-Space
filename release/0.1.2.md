# ArkSpace 0.1.2

This release adds bounded fetch-response retrieval, conservative research evidence metadata, credential input hygiene, and a read-only GitHub Issue/PR Skill.

## Highlights

- `web.fetch` can return opaque response IDs for later retrieval.
- `web.content.get` supports bounded offset/limit reads and exact text lookup from the private TTL cache.
- Research responses include source-level evidence identifiers without claiming passage or claim evidence.
- Credential references reject empty, placeholder, and control-character values.
- Added a read-only, bounded GitHub Issue/PR Skill using the local `gh` CLI.
- Local fetch remains explicitly opt-in; W13–W16 remain deferred until concrete consumers exist.

## Verification

- `npm run check`
- `npm run verify:release`

## Installation

```bash
npm install --global @arkspace/cli@0.1.2
```
