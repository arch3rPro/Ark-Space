# ArkSpace 0.1.3

This release adds explicitly configured keyless SearXNG search, multi-instance rotation, and a native terminal Setup workbench while preserving the shared CLI/MCP execution boundary. CLI and plugin metadata are aligned at `0.1.3`.

## Highlights

- **Keyless SearXNG search:** `web.search` connects only to explicitly chosen instances, with no public default or automatic discovery. Each instance has its own narrow CIDR authorization; DNS pinning, all-address checks, redirect validation, and bounded transport enforce the SSRF boundary. Multiple instances use a persistent transactional round-robin cursor, independent cooldowns, and classified safe failover within the shared deadline. Empty successful results do not trigger failover. Explicit SearXNG selection never switches to a hosted Provider, and configuration does not silently add it to automatic order. See [ADR 0013](../docs/adr/accepted/0013-searxng-keyless-self-hosted-search.md) and [ADR 0014](../docs/adr/accepted/0014-searxng-instance-rotation.md).
- **Multiple keyed-Provider credentials:** additive setup and reference registration preserve existing keys. Shared execution rotates keys only where retry safety permits; asynchronous creation does not retry or fall back while remote acceptance remains uncertain. Later Browser/Monitor operations stay pinned to their creating Provider and key reference, including cleanup. Rotation does not transfer resource ownership.
- **Native terminal Setup workbench:** Top, Menu, and Content are the three focus regions. Provider context, global order, and language remain independent. The provider strip renders every label as `[Name]`, with constant brackets, three-space gaps, classic centered placement, and a separate accent for each Provider. This is presentation, not a new backend. Masked local-key edit preloads the stored value; Add starts blank. Unchanged saves are no-ops. Changed saves validate before explicit overwrite confirmation; action and discard confirmations default to Cancel. Secure preview is read-only, masked by default, and ephemeral; no-color rendering remains supported. Environment precedence, shared-reference/owned-resource guards, explicit private-CIDR authorization, cancellation, and terminal restoration remain intact. See [ADR 0017](../docs/adr/accepted/0017-workbench-modal-setup.md).
- **Consent-bound diagnostics:** `t` offers a Cancel-default choice between a normal Provider pool test and sequential per-reference key tests. Individual tests use isolated temporary state, do not fall back or mutate global health/cursor/configuration, and skip unusable values without requests. `i` refreshes reference details, including a remaining-cooldown snapshot—not a live countdown. Session-only diagnostic history is explicitly historical, not validation of current credentials. Read-only navigation retains it; removed references are pruned, and attempted managed writes or normal pool tests clear it. No credential values or fingerprints are cached, so externally changed credentials cannot be detected from history.
- **Unicode-safe cached-content lookup:** case-insensitive literal search uses escaped Unicode-aware regular expressions (`iu`) against the original content, preserving original UTF-16 offsets instead of indexing a lowercased copy.
- **Canonical Skill packaging:** host manifests still reference canonical Skills directly. There are no generated plugin mirrors; only the Node/TypeScript CLI is built.

## Not included or qualified

Keyless Exa MCP access and Tavily/Firecrawl OAuth are research topics only, not implemented authentication backends. This release does not claim human UX acceptance, live SearXNG/paid-Provider qualification, or Windows/macOS real-TTY qualification. Synthetic Linux qualification is not evidence of those outcomes. Exact-tag installed-host, hosted-platform, and credentialed Provider qualification remain post-release work for the initial 0.1 line under [Maintenance](../docs/maintenance.md#plugin-release-boundary); replacement cutover remains separate.

## Installation

Install the pinned version:

```bash
npm install --global @arkspace/cli@0.1.3
```

For source development without replacing a global installation, use the built checkout as described in [INSTALL.md](../INSTALL.md#source-development). Node.js 20 or newer is required. Linux PTY development checks additionally require standard-library Python 3; end users do not.
