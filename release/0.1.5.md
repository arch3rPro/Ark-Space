# ArkSpace 0.1.5

Published on 2026-10-12 as a GitHub Release and npm package. This release contains changes since 0.1.4. Its published package requires Node.js `>=20.0.0`; do not attribute later Node.js `>=22.19.0` or the later pi-tui Setup rebuild to this release. CLI, MCP, package/lockfile, and versioned plugin metadata were aligned at `0.1.5`.

## Highlights

- **Manual npm CLI updates:** `arks update --check` checks the official stable npm release without configuration/credential bootstrap or npm execution. `arks update` verifies the npm-global target and asks `[y/N]`; empty input, EOF, and non-interactive input do not approve installation. Source, linked, local, and mismatched installations cannot self-update. See [ADR 0020](../docs/adr/accepted/0020-manual-npm-cli-update.md).
- **Research evidence review:** guidance distinguishes source-level evidence from verified passages, tracks support and gaps for consequential claims, bounds extra capability calls, avoids default resubmission of paid Research Jobs, and rejects instructions embedded in retrieved content. This is guidance, not a new backend or evidence guarantee.
- **Skill and Codex metadata:** Skill-local icons, notices, display names, descriptions, and prompts; Browser and Monitor are manual-only. Codex metadata adds a local marketplace source, project links, and capability labels.
- **Installation guidance:** English and Chinese READMEs use `@latest` and document separate `npx skills@latest check` / `update` commands. Native plugins continue through their host's plugin manager.
