# ArkSpace 0.1.0

ArkSpace 0.1.0 is the initial preview release of the greenfield Node.js and TypeScript runtime and its canonical Agent Skills.

## Included

- `arks` CLI with environment-referenced Exa, Tavily, and Firecrawl credentials, anonymous key ownership, rotation, cooldown, and retry-safety evidence.
- Protocol v1 request and response contracts for Web retrieval, crawl, extraction, Code Context, Research, Browser, Exa Monitor, and Firecrawl Site Monitor capabilities.
- Owned Firecrawl Browser sessions with bounded structured actions and explicit cleanup.
- Separate Exa recurring-search and Firecrawl site-monitor lifecycles.
- MCP stdio tools over the same capability dispatcher.
- Canonical `web`, `research`, `browser`, and `monitor` Skills with Claude Code and Codex plugin metadata.

## Requirements

- Node.js 20 or newer.
- Provider credentials supplied through configured environment-variable references.

Install after npm publication:

```bash
npm install --global @arkspace/cli@0.1.0
arks setup
arks doctor
```

## Preview qualification

This release does not replace or retire the previous ArkSpace repository. Hosted operating-system matrices, exact-published-version host installation, credentialed Provider E2E, and migration cutover validation are intentionally scheduled as post-release qualification. Use dedicated low-quota Provider accounts and inspect remote resources after every interrupted live run.

## Security

ArkSpace does not persist raw Provider keys. Browser and Monitor mutations require explicit confirmation, and owned resources remain pinned to the anonymous key identity that created them. Report vulnerabilities according to `SECURITY.md`.
