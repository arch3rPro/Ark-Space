# 设置 TUI 交互原型

Status: awaiting-browser-review

这是设计原型，不是正式 `arks setup` 实现。只使用合成数据，状态只在内存；不接受真实 API Key，不读取用户配置，不写凭据，不发 API 请求。

## 打开

用浏览器打开 `prototype.html`，保持同目录的 `prototype-model.js` 在旁。无需 npm 安装或构建。

如所在界面不能直接执行 HTML，可以把这两个文件一起下载后打开。也可自行在可信本地终端启动仅本机可访问的静态预览：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory .scratch/setup-tui-redesign
```

然后打开 `http://127.0.0.1:8765/prototype.html`；结束后 Ctrl-C 停止服务器。此命令不是本轮自动执行过的验证。

## 体验任务

页面外部的“测试场景”用于重置合成数据，不是产品菜单。

- 正常：选择密钥，添加、替换、停用、删除；确认默认为拒绝。
- 空态：检查添加入口是否足够明确，是否有假密钥。
- Many12：检查大量条目的选择、分页与焦点；不使用误导性数字编号。
- External：环境密钥不可替换但可取消引用；环境-only SearXNG 的唯一有效端点和 Provider 开关只读。显式新增本地实例会覆盖环境端点；删除最后本地实例可恢复环境来源。
- Owned：对象替换/删除与整个 Provider 停用受保护；单个密钥停用不删除清理引用。共享引用可取消但不可覆盖。
- Error：模拟保存失败，草稿保留，可重试或取消。
- Partial-save：合成凭据已保存但注册失败，保留孤立元数据，不加入配置列表，不声称回滚。
- SearXNG：实例只有添加/编辑/删除，没有单实例启停。规范化 URL 不变保留权限，端点改变清除旧权限；授权用 y/N，完全不连接 URL。
- 搜索顺序：调整草稿、跨页返回仍保留；明确取消才恢复，保存统一确认。
- 语言：只从全局侧栏切换，不增加 Provider 子菜单语言入口。

原型中的“测试连接”只产生模拟结果，不验证任何真实服务或凭据。禁止在 URL 等任意输入位置粘贴真实秘密。


18 项状态模型/脚本检查通过：场景与快照隔离、增删与选择、默认拒绝、环境/共享/拥有资源保护、环境 Provider 开关、顺序草稿、权限重置与授权、失败重试和部分保存、零请求模拟，以及脚本解析/无网络与浏览器存储调用检查；新增跨页草稿、环境-only SearXNG 只读、本地优先与环境恢复、无单实例开关、URL 词法限制、规范身份权限保留及首次配置默认行为检查。详细问题与证据见 `contract-audit.md`。
